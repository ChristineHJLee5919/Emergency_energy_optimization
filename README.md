# Emergency Energy Optimization Using Seoul Energy Simulation Data


## Overview

This project develops a Linear Programming (LP) model to optimize energy allocation during emergency situations such as blackouts or energy shortages.

Using Seoul Energy Simulation Data, critical facilities (Hospitals, Fire Stations, and Subways) were prioritized to maximize social utility under limited energy supply.


## Key Results

* Hospital: 100% protected in all scenarios
* Fire Station: 100% protected in all scenarios
* Subway: 100% protected in all scenarios
* Commercial facilities absorbed most reductions
* LP optimization outperformed proportional allocation

Python · Pandas · NumPy · SciPy · Linear Programming · Data Visualization
